# vcardqr

Generate **vCard 4.0 (RFC 6350)** QR codes with an optional **center logo badge**.

## Quickstart

```bash
make install
make runyaml
```

## YAML Input

Provide a YAML file with vCard + QR config, or override with CLI flags.

```bash
vcardqr --yaml examples/contact.yaml
```
